# CME Live-Data Cost Ablation V1

This retrospective diagnostic repackages the already completed, locked CME
futures-context development result into the operational question: does the
evidence justify purchasing a continuous live CME feed?

It compares the OANDA-reproducible spot setup, CME trades/volume confirmation,
CME official-statistics confirmation, and full CME confluence. This is not a
new confirmatory experiment: the source results were already observed, no
threshold was changed, and the sealed validation and dated-confirmation rows
remain unopened.

All four populations had negative average net R. No CME-dependent population
survived the original gates. The current conclusion is therefore
`NO_EVIDENCE_TO_PURCHASE_LIVE_CME`. Historical Databento data remains useful
for research, while forward operations should continue using reproducible
OANDA context until a genuinely new, preregistered CME mechanism provides a
reason to reconsider the recurring data cost.
